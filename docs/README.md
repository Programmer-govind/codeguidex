# CodeGuideX 🚀

**CodeGuideX** is a production-grade, AI-powered developer platform designed to accelerate learning, mentorship, and community-driven growth. Built as a Major Project for the 8th Semester, it integrates cutting-edge AI assistance with professional mentorship and cinematic learning resources.

## ✨ Key Features

-   **🤖 AI Studio**: Real-time code generation and debugging powered by **Google Gemini 2.5 Flash**. Features word-by-word streaming and intelligent context awareness.
-   **👥 Community Hub**: Specialized discussion boards for React, Next.js, AI, and more. Connect with 10,000+ developers globally.
-   **🎓 1-on-1 Mentorship**: Connect with senior engineers from top companies for personalized guidance and code reviews.
-   **🎥 Video Marketplace**: Cinematic masterclasses for engineers, covering Advanced Next.js, Postgres, and System Design.
-   **🛡️ Secure Auth**: Robust authentication via **Firebase**, supporting Google OAuth and secure email recovery.
-   **🎨 Premium UI/UX**: Modern, glassmorphic design system built with **Tailwind CSS**, **Framer Motion**, and **Outfit** typography.

## 🛠️ Tech Stack

-   **Framework**: Next.js 14 (App Router)
-   **Language**: TypeScript
-   **Styling**: Tailwind CSS + Vanilla CSS
-   **Animations**: Framer Motion
-   **Backend/Auth**: Firebase + Firestore
-   **AI Engine**: Google Generative AI (Gemini SDK)
-   **Communication**: Jitsi / Daily.co (Integration Ready)

## 🇮🇳 Localization

-   **Currency**: Fully localized to **INR (₹)** for Indian university requirements.
-   **Pricing**: Tiered plans designed for student and enterprise access.

## 🚀 Getting Started

1.  Clone the repository.
2.  Install dependencies: `npm install`.
3.  Configure Environment Variables in `.env.local` (Firebase, Gemini API, etc.).
4.  Run development server: `npm run dev`.
5.  Build for production: `npm run build`.
